# Looking after the documents (no technical knowledge needed)

The assistant answers questions from the documents in **one Google Drive folder**. You only work in that folder. Nothing else.

## What you do
- **Add a document:** put the file in the folder (or in a subfolder of it).
- **Update a document:** upload the new version with the **same name**, or edit the file in Drive. The old version is replaced.
- **Remove a document:** delete it from the folder (the Drive bin works as usual: restore a file from the bin and it comes back).
- Wait **about 10 minutes**. After that the assistant uses the new documents. (The maintainer can also make it immediate with the "Sync now" button.)

## Good to know
- **Good formats:** PDF, Word (.docx), PowerPoint (.pptx), Excel (.xlsx), Google Docs / Sheets / Slides, text, CSV, photos (.jpg, .png).
  Old Word and PowerPoint files (.doc, .ppt) must be saved as .docx / .pptx first.
- **Size:** up to 20 MB per file. For a very large document, split it into parts.
- **Give files clear names** ("Code des assurances CIMA 2019.pdf"): the assistant sees the names and uses them to find the right document.
- **Folders** are fine for organising (one level or several): keep the same names when you move a file.
- Scans of paper are read as pictures: a clean, straight scan works better than a photo taken at an angle.
- **Do not put confidential documents in the folder**: every person who uses the assistant can ask about every document in it.

## If something looks wrong
- A document is not used after 15 minutes: check that it is a good format and not too big, then tell the maintainer. The maintainer's page lists
  what was added and **what was skipped, with the reason**.
- The assistant says it cannot find something that is in a document: the file name or the contents may be unclear. Tell the maintainer
  the question and the document.
